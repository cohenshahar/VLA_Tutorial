## Key Physics Parameters

| Parameter | Location | Effect |
|-----------|----------|--------|
| `gear` (XML actuator) | model XML | Overall torque gain. 5=strong, 1=soft |
| `damping` (XML joint) | model XML | How fast motion bleeds off |
| `TORQUE` / `TORQUE_B` | Python | Command magnitude per keypress |
| `timestep` | `<option>` | Sim step size (0.005s = 200 Hz) |
| `Kp`, `Kd` | PD control | Spring gain / damper gain |

---

## Control Primitives (from Session 3)

```
ZERO:       ctrl[i] = 0                              → free fall
PD:         ctrl[i] = Kp*(target - qpos) - Kd*qvel  → hold position
SINUSOIDAL: ctrl[i] = A * sin(freq * t + phase)      → smooth wave
IK:         ctrl    = J† * cartesian_error            → reach 3D point
```
